# Alessandro Gregori: portfolio

A single-page portfolio of research, space, and personal engineering projects.

Live site: https://portfolio-qodviausy-alessandro-gregoris-projects.vercel.app/

## What's in this repository

- `index.html`: the whole site. The styles, images, video, and circuit diagrams are all inside this one file, so there is nothing else to install or build.

## View it locally

Open `index.html` in any browser. An internet connection is only needed for the web fonts; without it the page falls back to system fonts.

## Publish with GitHub Pages

1. Name the repository `Alessandro-Gregori.github.io` (or any name, with the steps below).
2. Upload `index.html` and this README to the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://alessandro-gregori.github.io` (for another repository name, `https://alessandro-gregori.github.io/<repo-name>`).

## Editing

Open `index.html` in a text editor. Text, links, and the colors at the top of the `<style>` block can be changed directly. Images and the video are embedded as base64 data, so to swap one, replace the long `data:image/...` or `data:video/...` string in its `<img>` or `<video>` tag.
